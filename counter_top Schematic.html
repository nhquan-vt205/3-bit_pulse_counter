counter_top

Sơ đồ khối và sơ đồ logic mức gate / flip-flop, dựng từ đặc tả hành vi. Toàn IP có đúng 4 flip-flop; mọi thứ còn lại — pulse, count_clr, overflow, rdata — là logic tổ hợp.

06 Phương trình logic của sơ đồ

Chú thích của các hình trên ở dạng phương trình, dùng làm đầu vào cho bước viết RTL. Đây không phải file RTL.

u_register
  cr_sel     = (addr == 10'h000)
  sr_sel     = (addr == 10'h004)
  cr_wr      = wr_en & cr_sel
  sr_wr      = wr_en & sr_sel

  pulse      = cr_wr & wdata[0]                        // CR.pulse_en  (WO,  one-shot)
  count_clr  = cr_wr & wdata[1]                        // CR.count_clr (W1P, one-shot)

  sr_ovf_clr  = sr_wr & ~wdata[3]                      // RW0C: ghi 0 thì clear
  sr_ovf_nxt  = (overflow | sr_overflow) & ~sr_ovf_clr // CLEAR ĐÈ SET
  // FF: async reset active-low → sr_overflow = 1'b0

  rd_word    = cr_sel ? 32'h0
             : sr_sel ? {28'h0, sr_overflow, count[2:0]}
             :          32'h0
  rdata      = rd_en ? rd_word : 32'h0

u_counter
  cnt_max    = count[2] & count[1] & count[0]          // == 3'b111
  overflow   = pulse & ~count_clr & cnt_max

  count_nxt  = count_clr ? 3'b000
             : pulse     ? (count + 3'b001)            // 3 bit ⇒ wrap 7→0
             :              count
  // FF × 3: async reset active-low → count = 3'b000

09 Điểm cần chốt trước khi viết RTL

Đã chốt: khi overflow và lệnh CPU ghi 0 vào SR.overflow xảy ra cùng cycle thì clear thắng — lệnh ghi của CPU luôn thắng. Đánh đổi đã biết: event overflow của cycle đó không được ghi nhận. Spec không quy định trường hợp này; testcase phải cover nó.
